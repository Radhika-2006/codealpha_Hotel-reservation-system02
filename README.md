# Hotel Reservation System 🏨

A responsive hotel booking web application built using HTML, CSS, JavaScript, and LocalStorage.

## Overview
This project provides a simple and user-friendly hotel reservation system where users can explore rooms, check availability, book rooms, and manage their reservations.

## Features
- User login with OTP verification
- Room availability management
- Room booking functionality
- Booking history
- Reservation cancellation
- Responsive design for different devices

## Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage

## Live Demo
https://radhika-2006.github.io/Hotel-reservation-system/

## How to Run
1. Clone this repository
2. Open `index.html` in your browser
3. Start using the hotel reservation system
